## 阻塞及验收边界

真实 B 站 README 课程和 YouTube 教学课程的原版 `--dry-run` 均退出 1：代理 `Tunnel connection failed: 403 Forbidden`，尚未取得元数据，更未读取视频。失败测试也有真实 B 站 WBI 请求漏出到网络；这是环境访问阻塞及测试隔离问题，不是已经证实的字幕算法错误。当前没有 `read_audio/read_media`，且原版 B 站字幕分支仅在有 SESSDATA 时执行；无 Cookie 即转音频。本次约束下不能绕过这些前置。
