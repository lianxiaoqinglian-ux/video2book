# 原版能力与学习目标对应

“代码实现”不等于“真实课程质量已验收”。下列位置相对于仓库根；以代码基线为准。已阅读 AGENTS、CLAUDE、README、SKILL、pyproject、CI、关键源码和现有测试。

| 用户需求 | 原版实现类别与证据 | 本次验证与差距 |
|---|---|---|
| Bilibili 字幕优先 | **代码**：`src/core/subtitles.py` 获取中文人工/AI 字幕、身份锚点、时长覆盖核验、块内相对时间轴；`src/pipeline.py:758` 受 `sessdata` 条件约束 | 相关离线测试可运行；真实接口 403。无 SESSDATA 主链跳字幕（`:772`），README“建议登录”不能理解成匿名字幕必可用 |
| YouTube 输入 | **代码**：`src/core/ingestion/youtube.py` 用 yt-dlp 解析/下载音频 | 实际元数据访问 403；主链非 B 站全部转音频（`pipeline.py:773`），没有复用 YouTube 自带字幕的主流程 |
| 长视频分块 | **代码**：`src/core/block_plan.py:440` 等，默认50分钟、长单集分腿、units/segments、锁定旧计划 | 现有行为测试与模拟重跑通过；真实2–10小时边界、资源成本尚未验证 |

| 截图、图表、画面公式、操作过程 | 文本表格、LaTeX、字符图有**提示词**支持；截图/关键帧/OCR/视觉事实输入**未发现实现** | `SKILL.md` 明确逐字稿唯一事实源，`taskbook.py:186` 不补写画面中未念出的代码/表格。归档教材0图片；不能保证屏幕独有知识被覆盖 |

| 例题、练习、答案解析 | **提示词/宿主**：learning `prompts.py:182–185` 只还原原课题目；legacy `:232–233` 可生成2–3题 | 不自动保证每章有练习。既有教材有SQL题目/答案；未运行数据库核对或比对题目所在原视频，正确性尚未验证 |

| 质量门禁 | **代码**：`core/quality_gate.py`、`deliverable_lint.py` 检查结构、实体覆盖、笔记成色和渲染/公式断裂 | 默认覆盖0.5，英文/中文两层任一过即可（`:53,310`）；不证明语义、推导、视觉、练习答案正确。归档渲染通过只能支持格式结论 |

## A/B/C/D 判断与最小缺陷

| 分类/优先级 | 判断 | 最小行动；本次不改核心代码 |
|---|---|---|
| A：已有并可复用 | 拓扑、锁定分块、音频物化、队列、缓存与基础门禁；长文/全书文件规范 | 继续使用原版CLI；已验证项以 RUNS 范围为限 |
| B：配置可解决 | 虚拟环境激活、访问域名；中文风格选择、明确已有信息的解释要求 | 使用已保存配置；来源标签/练习附录若与原版提示词冲突，需单独确认，不擅改 |
| C：可接受 | Markdown输出、按时长先分块、固定过渡、无网页平台；第一阶段不强求部署 | 不开发UI、不重写整编器，不因为这些限制淘汰项目 |
| D/P0：真实入口阻塞 | 403网络、缺指定听音通道；无Cookie时B站字幕分支不可走 | 配置生效后重试元数据；在已有支持宿主验证原版听音。不能保证仅开放域名就解决平台限制 |
| D/P1：视觉事实缺口 | 屏幕独有知识没有进入唯一事实源的机制 | 同一小样本做画面遗漏审计，实证后才比较现成截图/OCR功能的最小复用 |
| D/P1：时间/来源透明 | 听音无时间戳；静默修正不留证据 | 先实测字幕时间映射及纠错实例；可能需增加侧车索引/明确补充标签，提出建议后等用户确认 |
| D/P1：质量与答案 | 关键词命中、文本够长都不能证明讲全讲对 | 10个知识点和实际原课案例/练习逐项核查，不先改门禁或生成一套新题库 |
| D/P2：测试隔离 | 一个WBI降级测试漏出真实导航请求 | 建议未来仅在该测试中 mock WBI key 取得，保留现有断言；本次不改测试、不跳过失败 |
| D/P2：长课与整编 | 具备机制，缺2–10小时真实故障/质量证据 | 放到第3阶段；先验证短样本，不现在扩展全框架 |

不建议现阶段整合 BiliNote、另装转录系统或大范围重复调研。继续用原版的理由是成熟的内容流水线和状态工具；继续的前提是承认视觉、追溯与知识验收尚有实质差距。
